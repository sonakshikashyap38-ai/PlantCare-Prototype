PlantCare 🌿

About the Project

PlantCare is a beginner-friendly plant care concept designed to help people understand and care for their indoor plants.

This project is presented as a no-code clickable prototype created using Canva.

Problem Statement

Beginners often find it difficult to understand when a plant needs water and how to recognize common plant health symptoms.

Proposed Solution

PlantCare explores a simple and user-friendly way to:

- Explore plant care information
- Understand common symptoms such as yellow leaves
- Learn about possible causes of white powder on leaves
- Discover basic plant care suggestions
- Maintain a plant care routine
